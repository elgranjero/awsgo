# awsgo

`awsgo` is a generated, AWS CLI-style command-line tool built with Go and Cobra, targeting broad AWS SDK v2 service coverage.

## Status

Pre-release and private.

## Private Backup

Use the helper script to initialize, commit, tag, and push this tree to an
existing private GitHub repository with your default Git identity:

```bash
scripts/private-first-push.sh --repo awsgo
```

The repository must already exist on GitHub and should be private. Use
`--no-push` to stop after configuring the local repository and remote.
